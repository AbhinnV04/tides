# Tides

How few numbers does it take to predict the ocean? Starting from the data: find the system's own frequencies, fit a straight line in those coordinates, measure how fast each extra term stops paying, and see what's left over.

Work in progress. The hypotheses are written down before the analysis, and every one ends in a verdict, including the nulls.

**Data:** none is stored in this repo. The scripts fetch it from NOAA's public tide-gauge API.
